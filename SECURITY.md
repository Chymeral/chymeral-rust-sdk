# Security Policy

## Supported versions

| Version line | Supported |
| --- | --- |
| 1.7.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Do not disclose suspected vulnerabilities through a public issue, discussion,
or pull request. Use this repository's GitHub private vulnerability-reporting
channel when it is available. Repository maintainers should keep that GitHub
setting enabled.

If private reporting is temporarily unavailable, contact a repository owner
privately through GitHub with the affected version and platform, impact,
reproduction steps, and any proposed mitigation. Please allow maintainers to
coordinate a fix before public disclosure.

This policy covers the Rust SDK's CLP framing, parsing, client lifecycle, and
conformance executable. Chymeral host vulnerabilities should instead be
reported through the [core repository](https://github.com/Chymeral/chymeral).
